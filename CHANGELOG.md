# Changelog

## 2026-10-19

### Изменено

- В README уточнены обязательные поля зоны, ошибка некорректной фракции в `setOwner()` и запуск примера через `tsx` из корня репозитория.

- Дополнены существующие тесты: данные событий захвата, потеря неполного интервала дохода и состояние у второго подписчика после запрещённой смены владельца.

- В README добавлены игровое и техническое обоснования прямого захвата, включая ограничения выбранной модели.

### Исправлено

- Игроки на границе зоны, например (99, 168) при радиусе 195 и (21, 220) при радиусе 221, учитываются внутри: для обычных значений сравниваются квадраты расстояния и радиуса. Для переполнения и слишком малых квадратов сохранён расчёт через `Math.hypot`.
- Добавлены регрессионные тесты граничных точек, исключения игроков снаружи и геометрии с радиусами `1e200` и `1e-200`.
